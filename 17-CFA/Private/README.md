# Private

CFA material that must never be published lives here.
Everything in this folder except this README is gitignored and never leaves your machine through git.

| Path | Content | Why it is private |
|---|---|---|
| `CFA-L-1/` | Level I notes imported from OneNote: reading checklists, copied summaries and practice problems | Reproduces CFA Institute curriculum text |
| `CFA-L-2/Kaplan/` | Kaplan and IFT slide notes | Embeds third-party slide images |
| `CFA-L-2/40-Formula-Sheets/Official-*.md` | The official ratio and abbreviation lists | Verbatim CFA Institute reference documents |
| `CFA-L-2/Practice-Problems/` | One note per learning module: the end-of-module problems restated with solutions, embedded by the module note's Practice problems section | Restates CFA Institute curriculum problems |
| `Attachments/` | The slide and problem images those notes embed | Third-party images |
| `Curriculum-PDF/` | The curriculum PDFs, if you keep them here (the pipeline's default `CFA_PDF_DIR`) | CFA Institute copyright |

Obsidian resolves wikilinks and image embeds by file name across the whole vault, so these notes keep working where they are.
It is not backed up by the repository: keep your own private backup (for example a separate private repository inside this folder, or your private notes vault's history).
