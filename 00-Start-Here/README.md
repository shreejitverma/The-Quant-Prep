# Start Here

1. Pick your track or tracks in [Tracks](Tracks.md).
2. Read the [Roadmap](Roadmap.md) for the phases and the weekly rhythm.
3. Set up the platform with [Using the Platform](Using-the-Platform.md): `./qp profile`, then `./qp serve --open`.
4. Study what `./qp next` suggests; mark mastery as you go; review cards daily.
5. Before interviews, work the [firm guides](../14-Firms/README.md) for your targets.

Software engineering preparation lives in SDE-Interview-Prep; the [SDE Link Map](SDE-Link-Map.md) shows what to take from it.
Authors: the rules for notes and cards are in [Note Conventions](Note-Conventions.md).
